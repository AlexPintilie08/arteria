# Analiza instrumentelor concurente și complementare

**Accesarea paginilor:** 18 octombrie 2026. Funcțiile și prețurile comerciale se pot schimba. Descrierile de produs sunt afirmații ale producătorului, nu benchmark independent. ARTERIA nu a fost comparată prin același caz sau set de date cu aceste produse.

## Poziționare

ARTERIA de azi poate fi explorată ca prototip web conectat pentru comparații sintetice de verde semaforic și screening pietonal pe graf. Produsele profesionale din lista solicitată fac analiză GIS, model de cerere, simulare microscopică ori modelare multimodală cu o profunzime și un domeniu diferite. Asta nu impune copierea funcțiilor lor. Prima versiune profesională ARTERIA ar trebui să rezolve un caz îngust, verificabil, apoi să decidă dacă instrumentele de simulare sunt concurente, motoare integrate sau surse de validare.

## Costuri și licențiere, interpretare pentru România

- **Prețuri publice verificabile la accesare:** Aimsun Next (EUR/an/seat) și Bentley OpenPaths (USD/an). Nu s-au adăugat taxe, TVA, curs valutar, service/support sau reduceri condiționate.
- **Fără preț comercial numeric pe paginile verificate:** PTV Vissim/Visum și ArcGIS Pro; solicitați cotație locală pentru comparație de achiziție. Nu transferați prețurile SUA în bugetul României.
- **Open source:** QGIS, SUMO, MATSim, OSMnx și OpenTripPlanner evită taxă de licență de bază, dar cer hardware, administrare, formare, date, expertiză și suport.
- OSM data folosește ODbL cu atribuirea cerută; identificarea și compatibilitatea licenței pentru derived database trebuie analizate de proprietarul produsului [OSM copyright/license](https://www.openstreetmap.org/copyright).

## Opinii și nemulțumiri: ce se poate afirma

Nu a fost găsit un eșantion reprezentativ de recenzii profesionale. Au fost folosite câteva issues GitHub ca exemple concrete de probleme de tooling, cu statut și dată:

- QGIS endpoint snap la rețea prea îndepărtată a fost o problemă soluționată prin parametru opțional; false intersections la pod/underpass este un issue raportat în 2025, încă deschis în pagina accesată.
- OSRM issue-uri discută sidewalk=separate și interpretarea permission/access pentru pedestrian profile; sunt cazuri specifice de tagging/routing, nu „OSRM e greșit în general”.
- SUMO issue #17399 a fost bug de regresie în GUI calibrator, fixat în decembrie 2025; FAQ cere reproducere minimă și include rețea, config și fișiere input.

Aceste cazuri justifică un set de controale în produs: snap distance, disconnected/bridge topology validation, audit OSM tags, warnings pentru lipsă de atribute, input manifest, versions și reproducere. Ele nu dovedesc că ARTERIA poate evita toate problemele sau că un instrument anume are utilizatori nemulțumiți pe scară largă.

## Cum să compare ARTERIA corect

Folosiți aceeași arie și snapshot și evaluați taskuri, nu liste marketing:

1. Import și QA pe GeoPackage/OSM, identificarea disconnected links și a layer-elor fără atribute.
2. Service area / shortest path cu point snapping și raport de elemente ne-rutabile.
3. Intervenție pietonală ipotetică: baseline/scenario, geometrie în hartă, metrici și export verificabil.
4. Semafor: aceeași geometrie/faze/volume, method/version, măsurători și calibrare; țineți modelul sintetic în afara comparației de precizie.
5. Efort, reproducibilitate, transparență, cost total și compatibilitatea cu procesul echipei.

Nu declarați superioritate sau economii de timp fără studiu comparativ și participanți.
